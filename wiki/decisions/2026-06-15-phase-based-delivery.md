# Decision: Phase-Based Delivery For Temptwin Platform

## Status

- Accepted

## Context

- The project starts from a blank repository.
- The user asked first for a specification, then a phased structure, then a roadmap that an AI can later implement.
- Combined CRM and project management systems can sprawl quickly if scope is not sequenced deliberately.

## Decision

- Start with a product specification before code.
- Organize delivery into sequential phases with explicit outcomes.
- Build a shared platform foundation before advanced automation or AI features.
- Treat CRM and project management as one connected product with a shared data model and handoff flow.

## Consequences

- The first artifacts are documentation and planning assets instead of application code.
- Later implementation work can be broken into smaller AI-friendly tasks.
- Some domain details remain provisional until Temptwin-specific workflows are validated.
