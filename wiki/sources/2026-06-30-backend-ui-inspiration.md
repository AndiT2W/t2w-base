## Takeaways

- Stripe is the strongest reference for dense tabular admin UIs with strong search and clear account-oriented navigation.
- Supabase Studio is useful for split-pane workspaces and technical/admin content density.
- Retool is a good reference for KPI cards, tables, filters, and internal-tool clarity.
- Vercel is useful for polished navigation, quick project switching, and modern dashboard chrome.

## Notes

- These are inspiration references only and should not be copied literally.
- The current Penpot table view aligns most closely with Stripe/Retool-style admin density.
- On 2026-08-17, the user proposed Invoice Ninja as an additional visual reference: persistent left navigation, a global search field in the top bar, and a compact operational workspace. A T2W adaptation should use domain areas such as Veranstaltungen, Kontakte, Aufgaben, Rechnungen, and Kommunikation rather than invoice-only navigation.
