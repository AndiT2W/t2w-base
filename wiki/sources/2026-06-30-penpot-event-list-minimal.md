# Penpot Event List Minimal

Rendered and imported a slim MVP event-list mockup in Penpot.

## Characteristics

- Separate Penpot page: `Event List MVP`.
- Table-focused overview with the core MVP columns:
  - eventcode
  - eventname
  - status
  - date
  - organizer
  - registration contact
  - finance contact
  - `t2w_event_id`
  - completeness
- Compact filter chips for the current event statuses.
- Lightweight KPI cards at the bottom for contact coverage, TIME2WIN linkage, and completeness.

## Notes

- This list is intentionally aligned with the existing `Event Detail MVP` page.
- It stays within the MVP scope and avoids extra CRM or finance widgets that are not yet part of the agreed first version.
