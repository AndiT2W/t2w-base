# Penpot Event Detail Minimal

Rendered and imported a slim MVP event-detail mockup in Penpot.

## Characteristics

- Left navigation with the core areas only.
- Header with event name, compact eventcode, status chip, and a small `TIME2WIN öffnen` action.
- Main card with only the MVP essentials:
  - event dates
  - location and address
  - organizer
  - organizer contacts
  - OneDrive folder reference
  - Eventfinance folder reference
  - optional owner indicator
  - internal team members
  - invoice summary
  - manual timeline
  - completeness subcategories

## Notes

- This variant intentionally stays small and avoids dashboard clutter.
- It reflects the current MVP scope: manual timeline only, no automatic comms aggregation, and no extra file-link block beyond the two folder references.
