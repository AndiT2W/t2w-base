# Penpot Stripe Admin Table View

Rendered and imported a new Penpot mockup focused on a Stripe-like admin backend with stronger table emphasis.

## Characteristics

- Left sidebar for dashboard navigation.
- Top search and primary action button.
- Four KPI cards for volume, open invoices, sent offers, and next payment.
- Main `Events & Rechnungen` table with filters and status pills.
- Right detail panel for selected event metadata, contacts, and invoice summary.

## Notes

- This variant is meant to be more tabular and calmer than the earlier Stripe home-style dashboard.
- The SVG version was rasterized to PNG before importing into Penpot because direct SVG upload was rejected by the current Penpot upload flow.
