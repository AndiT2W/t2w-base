## Design reference to carry over

- German-language responsive admin web app.
- Dark left navigation and light main work surface.
- Operational event list as the primary view.
- Search, status/period/archive filters, configurable team columns.
- Month and week calendar with multi-day events rendered as bars.
- Event creation in a dialog; editing on the event detail page.
- Detail tabs for master data, contacts, tasks, files, and communication.
- Calm, professional internal-tool styling with demo data as the original prototype state.

## Superseded prototype assumptions

The Lovable project description still contains the earlier status set (`Entwurf`, `Angefragt`, `Zugesagt`, `Abgeschlossen`, `Storniert`) and a risk column. The current domain decisions supersede those assumptions:

- statuses are `Anfrage`, `Angebot gesendet`, `Zugesagt`, `Abgesagt`, `Akquise`, `Datum prüfen`;
- risk is not an event field.
