# Domain Docs

This is a single-context repository.

Before exploring implementation work, read:

- `CONTEXT.md` at the repository root if it exists.
- `docs/adr/` for relevant architectural decisions if it exists.
- `wiki/overview.md` and the relevant linked wiki pages for current project knowledge.

If context or ADR files do not exist, proceed without creating them just for setup. Use the project's established domain vocabulary, especially Event, Organizer, Contact, Offer, Invoice, Credit, and TIME2WIN.

If a proposed change conflicts with an existing decision, surface the conflict explicitly before implementing it.
